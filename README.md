# NextGen-Telecom
Este es un proyecto del SENA del programa de Telecomunicaciones basado en una simple wiki informativa es una Plataforma interactiva desarrollada como proyecto. Contiene manuales técnicos y herramientas de diagnóstico para resolución de incidencias en redes FTTH,Wi-Fi y LAN Incluye guías interactivas de enrutamiento y un análisis profundo
